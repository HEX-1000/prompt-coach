# Security

## Supported versions

The latest version only. Installed copies update themselves.

## Reporting a vulnerability

Report it privately through this repository's Security tab: "Report a vulnerability". Please do not open a public issue for a vulnerability.

## In scope

- The updater. It downloads and runs code from this repository.
- The reading of `include:` paths in context files.
- Anything that would send a prompt, a context or a history record off the PC.

## Out of scope

- Vulnerabilities in Ollama itself.
- What the model answers.

There is no promise about response time.
